# perport

Personal site for Felipe Carvajal Brown, built with Eleventy (11ty). Static, bilingual (Spanish default, English under `/en`), deployed to `fcarvajalbrown.github.io/perport`.

## Develop

```bash
npm install
npm run serve
```

## Build

```bash
npm run build
```

Output goes to `_site`. Content lives in `src/`: `portfolio/`, `works/`, `writing/`, and `index.md` for the landing page.
